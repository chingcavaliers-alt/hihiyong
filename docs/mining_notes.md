## 2026-11-08 示範錄製：欸等在水晶礦場（Logs\Recordings\20261108_194709_欸等，75 秒）
地圖 213-0「水晶礦場」。上面「礦石清單是空的」那段是我讀錯：水晶礦場的「能原石」其實是**怪物清單（LandCrowListOffset）裡的物件**（原生 ID 1-7～1-16、血量 200000），不是採集物清單；所以 MaterialError（採集物位置沒推算出來）不影響採礦。讀礦石用 MiningCrows(pid,"能原石")。

### 採集的玩法（從錄製與截圖看到的）
- 採礦工具：背包裡的「十字鎬」（1-353）。說明寫：放在背包中，靠近可採集的礦點，右鍵使用，採集需 60 秒，再次使用可停止。
- 流程：左鍵點地面走到礦石旁（一次錄到 9 下點擊，每下約 0.2 秒、一段約 25～30 單位的路）→ 停下 → 在背包視窗右鍵十字鎬（螢幕 (965,217)、(961,228)，就是十字鎬那格）→ 角色動作變「採集」。
- 採集持續約 60 秒（5.98s 開始，65.97s 礦石數少一顆）；這 60 秒角色完全不動。
- 聊天欄：「開始採集 → 取得道具 '綠水晶' → 採集成功」。採完那顆礦石從清單消失。
- 採集時動作值 = 採集（GLAT_GATHERING = 6）。第一次點礦是走到礦石旁約 13 單位的位置（綠能原石 #6，位置 (-388.3,-25.4,-481.4)，角色停在 (-376.2,-25.5,-475.6)）。

### 礦石資料
- 這張圖約 66～75 顆「能原石」，會隨角色移動載入 / 卸載（66 → 75 顆）。
- 種類：綠 1-7 / 1-8、紅 1-11 / 1-12、紫 1-15 / 1-16、藍 1-13 / 1-14、黃 1-9 / 1-10。礦石血量固定 200000、動作固定「待機」，採集不影響這兩個值。
- 背包裡的產物：紅水晶 347-76、綠水晶 347-74、紫水晶 347-78（採到的水晶種類跟礦石顏色對應，尚未逐一對照）。

### 王（使用者說明，2026-11-08）
- 水晶礦場地圖上標「B」的紅點 = 王固定重生的地點；王每 2 小時重生一次。
- 打王**不能用 F6 自動打怪**。使用者的打法：選好固定的技能（右鍵技能），**壓住右鍵、游標放在王的血條身上一直打**。
- 自動化的做法（構想）：走到王旁邊 → 確認技能欄 / 右鍵技能是指定的那個（MiningCharState 讀得到 skillBar、runSkill）→ 用 GameWorldToScreen 算王的血條在畫面上的位置（王的座標 + 高度）→ 按住右鍵（mouse_event RIGHTDOWN），每 0.3 秒重新對準游標（王會移動）→ 讀王的血量到 0 / 消失就放開；人物死亡、使用者動鍵鼠、超時、右鍵一定要在 finally 放開。
- 待確認：王的名稱 / 血量 / 攻擊範圍、使用的技能（技能欄第幾排、右鍵技能）和射程、王打人的強度（人物會不會死）、B 點座標（有幾個點）。
