HIHIYONG 多帳號管理器 — 使用說明

【開啟程式】
  第一次：解壓縮後雙擊「HiHiyong帳號管理.bat」，Windows 詢問是否允許變更時按「是」。
  之後：桌面會自動出現「HiHiyong帳號管理」捷徑，直接從桌面開即可，不用再進資料夾。
  （遊戲是用系統管理員身分執行，管理器也必須用系統管理員身分才能讀取遊戲資料。）
  資料夾搬到別的地方後，從新位置雙擊一次「HiHiyong帳號管理.bat」，桌面捷徑就會跟著更新。
  想換桌面圖示：設定 → 其他 → 「更換桌面圖示」，選一張 png / jpg / ico 圖片即可。

【第一次在這台電腦使用】
  1. 設定 → 帳號：每個帳號重新輸入一次「遊戲密碼」後按「儲存帳號」。
     密碼是用 Windows 內建加密保存，只有原本那台電腦能解開，所以換電腦要重填一次。
  2. 設定 → 啟動與登入、通知與報表：
     - 「選擇啟動程式」指到這台電腦的遊戲 Launcher。
     - 有使用 Discord 通知的話，重新貼上通知網址並儲存。
     - 按「檢查既有設定」，依照提示完成沒通過的項目。
  3. 設定 → 帳號 按「自動連接遊戲視窗」，再回首頁按「開始監控」。

【需要注意】
  - 遊戲畫面請維持 1024×768，Windows 顯示縮放比例和原本的電腦相同，
    自動登入與每日道具自動更換才點得到正確位置。
  - 遊戲維修更新後，第一次啟動會自動重新準備讀取位置，大約需要幾十秒，
    這段時間血量、背包統計、每日道具會先顯示「讀取中」。
  - 任何時候按 F10 都能立即停止所有自動操作（遊戲不會被關閉）。

【資料夾內容】
  app\            程式本體與設定（不需要手動修改）
  app\runtime\    附帶的 AutoHotkey 與 Python，這台電腦不用另外安裝
  app\Stats\      每日背包統計紀錄
  app\Logs\       執行紀錄（第一次執行後產生）

【需要另外安裝的】
  Microsoft Edge WebView2 Runtime（Windows 10 / 11 通常已內建）。
  如果開啟後畫面一片空白，到微軟官網搜尋「WebView2 Runtime」下載安裝即可。
